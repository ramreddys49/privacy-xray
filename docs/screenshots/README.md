# Screenshot capture notes

This folder is for optional README screenshots. Files are not generated automatically.

Suggested captures after `npm run dev`:

1. `user-view.png` — User View with Digital Twin and a personalized or contextual ad
2. `engineer-view.png` — Engineer View showing the live event console and processing pipeline
3. `blocked-analytics.png` — Analytics off, Travel (or similar) event observed but not processed
4. `privacy-violation.png` — Engineer View after Simulate privacy violation, with the detector alert visible

Use a desktop viewport for README images. After the files exist, add relative image tags in the root `README.md` Project screenshots section.
